# Encryption Project

## Overview

Encryption Project is a Java-based application developed as a university project. The system allows users to encrypt text using different cryptographic algorithms while demonstrating fundamental concepts of information security and cryptography.

## Features

* Encrypt text using multiple algorithms.
* Apply different cryptographic techniques.
* Interactive user interface.
* Educational implementation of encryption concepts.

## Project Structure

* **Code/**: Contains the source code and implementation files.
* **Documents/**: Contains project documentation and supporting materials.

## Purpose

The project was developed to explore encryption techniques, strengthen programming skills, and gain practical experience in implementing cryptographic algorithms.
